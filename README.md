# 🩸 BloodConnect – Blood Donation Management System

BloodConnect is a **web-based Blood Donation Management System** developed using **Python and Django**. The application helps manage blood donors and blood requests through a simple and user-friendly platform.

It provides features for registering donors, managing donor information, submitting blood requests, and maintaining records efficiently.

---

## 🚀 Features

* 👤 **Donor Registration**

  * Add donor details
  * Blood group selection
  * Age and gender validation
  * Phone number validation
  * Hemoglobin validation
  * State and city selection
  * Last donation date tracking

* 🩸 **Blood Request Management**

  * Create blood requests
  * View available requests
  * Update request information
  * Delete requests

* 🔐 **User Authentication**

  * User login and logout
  * Protected application pages
  * Separate access for users and administrators

* 📊 **Donor Management**

  * View registered donors
  * Update donor information
  * Delete donor records
  * Search and manage donor details

* ✅ **Eligibility Validation**

  * Age-based eligibility
  * Hemoglobin validation
  * Donation interval validation
  * Health-related eligibility checks

  * Bootstrap 5.3
  * Font Awesome icons
